# Create Blazor Input Mask in Blazor Webassembly App

A ready-to-run Blazor WebAssembly application demonstrating the [Blazor Input Mask](https://www.syncfusion.com/blazor-components/blazor-input-mask) component with practical formatting capabilities.

## Overview

This project showcases how to integrate and configure the Blazor Input Mask component in a Blazor WebAssembly app. The Input Mask component enables structured data entry by enforcing specific input patterns, such as phone numbers, zip codes, or PIN codes, improving data quality and user experience.

## Features

- **Flexible Masking Patterns** – Support for various input formats
- **Event Handling** – Responds to keyboard and value change events
- **Bootstrap Styling** – Built-in responsive UI framework
- **Fluent2 Theme** – Modern, accessible design system

## Prerequisites

* [.NET SDK 10.0](https://dotnet.microsoft.com/en-us/download/dotnet/10.0) or later
* [Visual Studio 2022](https://visualstudio.microsoft.com/vs/) or later
* [Visual Studio Code](https://code.visualstudio.com/)

## Getting Started

### Clone the repository

```bash
git clone https://github.com/SyncfusionExamples/blazor-input-mask-webassembly-app.git
cd create-blazor-input-mask-in-blazor-webassembly-app
```

### Run with Visual Studio

1. Open the solution file using Visual Studio 2022 or later.
2. Restore the NuGet packages by rebuilding the solution.
3. Build the project to ensure there are no compilation errors.
4. Run the project.

### Run with .NET CLI

```bash
# Restore dependencies
dotnet restore

# Run the project
dotnet run
```
